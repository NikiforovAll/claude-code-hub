Hold <kbd>Ctrl+Shift+Space</kbd>, speak, and let go. The hub turns what you said into an action: it starts a new session, or types your words into the session on screen as a prompt for you to review. Your words show up as you speak. To send the prompt at once, press <kbd>Enter</kbd> before you let go.

<Shot src="shots/extensions/voice-live-new-session.webp" alt="Kanban's New session dialog opened by voice while the user still speaks: the Prompt field shows &quot;Fix the flaky login test and then run the&quot; and a Listening pill sits at the bottom of the hub window" width={3840} height={2160} />

Voice is off by default. You turn it on with the [Voice control extension](/claude-code-hub/extensions/voice/).

## Before you start

- **Hex (recommended, Windows).** [Hex](https://anoma.ly/hex) does the speech to text, on your machine. Get the Windows installer from its [website](https://anoma.ly/hex) or its [releases](https://github.com/anomalyco/hex/releases). Install it and start it once, so that it downloads its speech model. Hex must be running while you use voice. Without Hex, see [Without Hex](#without-hex).
- **The embedded terminal.** Kanban sends prompts to the session in its [embedded terminal](/claude-code-hub/guides/terminal/). A session that runs in another terminal does not get them.

<Shot src="shots/extensions/voice-hex.webp" alt="The Hex website: &quot;Speak. It appears.&quot;, local voice dictation for Windows, with the Windows installer and a PowerShell install command" width={2800} height={1560} />

## Turn voice on

```bash
claude-code-hub ext install voice
```

The command turns voice on in the hub's `config.json`, and tells you when Hex is not installed. Then restart the hub.

To turn voice off again:

```bash
claude-code-hub ext remove voice
```

## Talk to the hub

Hold <kbd>Ctrl+Shift+Space</kbd> while you speak. A pill at the bottom of the window shows **Listening**. Let go of the keys when you are done.

Your words show up while you speak, about once a second: in the session's input box, or in the Prompt field of the New session dialog. When you let go, the final text replaces them and stays in the input box. Read it, then press <kbd>Enter</kbd> to send it.

To send without the review, press <kbd>Enter</kbd> while you still hold the keys. The pill shows **sends on release**, and the prompt is sent when you let go.

To change your mind, press <kbd>Backspace</kbd> while you still hold the keys. The hub stops listening, removes the words it typed and sends nothing. A New session dialog that your words opened closes. Then let go.

The first time, the hub window asks to use your microphone. Allow it: the hub records while you hold the keys and sends the sound to Hex on your machine. If you block it, or your Hex has no live text, Hex records and your words show up only when you let go.

Hex keeps <kbd>Ctrl+Space</kbd> for plain dictation into any app, so both work side by side.

### Without Hex

When Hex is not installed, the hub uses the browser's speech recognition (Chrome or Edge), on any OS. It works the same way: hold the keys, speak, let go. The difference is privacy: the browser sends the sound to an online speech service while you hold the keys. The first time, a note in the hub window tells you so.

To pick one yourself, set `provider` in [Settings](#settings).

A command starts with the word "Hub". Everything else is a prompt.

| Say | The hub |
| --- | --- |
| "Hub, new session" (also "Hub, start a session", "Hub, session") | Opens Kanban's New session dialog |
| "Hub, new session, fix the flaky login test" | Opens the dialog with "fix the flaky login test" as the first prompt |
| "Hub, add a task, fix the login page" (also "Hub, new task …", "Hub, task …") | Adds a pending task "fix the login page" to the board of the session on screen. With no words after it, opens the board's Add task input. A task longer than 8 words is split at its first comma or period: "fix the login page, the button does nothing on Safari" becomes the title "fix the login page" and the description "the button does nothing on Safari". Your words are never changed |
| Anything else | Types it into the session on screen as a prompt. <kbd>Enter</kbd> during the hold also sends it |

"Hub" must be the first word. Once the hub hears it, nothing more goes into the session: the pill shows the command as you speak. "Hub" followed by words that are not a command shows a toast.

Not sure what to say? Hold the keys and say only "Hub". A panel at the bottom right lists the commands you can use on this tab. It closes when you say a command, and stays a few seconds if you let go.

### On another tab

On a tab other than Kanban, voice runs only commands, and "Hub" is optional: "add a task, fix the login page" works. Kanban comes on screen and does what you said. Other words are not typed into a session you cannot see. A toast shows them instead.

### Where a new session starts

"Hub, new session" opens Kanban's New session dialog as soon as Hex hears it, while you keep speaking. The words after it go into the Prompt field, so you see what starts before it starts. The folder is that of the session on screen, else the project that Kanban's project filter shows, else the most recent project. Press <kbd>Enter</kbd> to start it, or change a field first.

### When a prompt is not sent

A prompt goes to the session whose terminal is on screen. While Claude works, it queues the prompt and runs it next. When no session terminal is on screen, nothing is sent: a toast shows what you said, with a **Copy** button.

Kanban does not send a prompt while Claude shows a dialog, because the Enter press would answer it. A toast tells you so.

## Dictate in the New session dialog

The microphone button in Kanban's New session dialog uses Hex too, when voice uses Hex. Click it, speak, and click it again: the text goes into the Prompt field where the cursor is. Nothing is sent until you press **Start**.

Otherwise (voice off, voice through the browser, or Kanban alone), the button uses the browser's speech recognition.

## Settings

The extension writes `voice` in the hub's `config.json`. You can change it by hand, then restart the hub.

```json
{
  "voice": { "enabled": true, "provider": "auto" }
}
```

| Key | Default | Meaning |
| --- | --- | --- |
| `enabled` | `false` | Turns voice on |
| `provider` | `auto` | What turns speech into text: `hex`, `browser`, or `auto` (Hex when it is installed, else the browser) |
| `taskSplitModel` | none | A Claude model, such as `haiku`, that finds where a long task with no comma or period ends its title. It runs `claude -p` on your machine, so it uses your Claude plan: about $0.0002 and 3 seconds per such task |
To use another key, set `hub.voice` in [`keys`](/claude-code-hub/reference/shortcuts/#change-the-keys).

## When it does not work

- **Nothing happens when you hold the keys.** Voice is off, or the hub did not restart after you turned it on.
- **"Voice: hex …" toast.** Hex is not installed or not running. Start Hex and try again.
- **"Speech recognition: not-allowed" or "network".** The browser blocked the microphone, or cannot reach its speech service. Allow the microphone, check the network, or install Hex.
- **"No speech".** Hex heard nothing. Check the microphone that the hub window uses (the camera icon in the address bar of a browser tab, or Chrome's site settings for the app), and the one that Hex uses.
- **The words are wrong.** Each attempt is in `<hub dir>/voice.jsonl`, one line per attempt, with what Hex heard and what the hub did with it.
